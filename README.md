# HMF Design Clinic

The **Cedarline HMF (Hybrid Mesh Firewall) Design Clinic** — a Cisco Secure
team playbook activity page.

A regional health group has budget, executive attention, and no plan. Four
players, forty minutes, six rounds, two ways to win. The page is a
self-contained participant playbook: the customer and current-system
breakdown, the discovery-call briefing transcript, how to play (deliverables,
the WIDE/DEEP decision, four seats), the six-round board, the nine-slot design
canvas, the three submission sheets, the scoring rubric, and a worked
"what good looks like" example.

## Contents

- `index.html` — the standalone playbook page (inline CSS, no build step).

## Viewing it

Open `index.html` directly in any browser, or enable **GitHub Pages**
(Settings → Pages → Deploy from branch → `main` / root) to publish it at
`https://<owner>.github.io/hmf-design-clinic/`.
