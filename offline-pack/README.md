# Offline pack — paper backup for the HMF Design Clinic

Run the clinic without the website if you need to. Print and hand out:

- **HMF-Activity-Guide.docx** — give one to every team. Explains the task, the
  customer scenario, how to write a good answer, and how scoring works.
- **HMF-Answer-Sheet-UC*.docx** — the four blank answer sheets (one per use
  case: AI Security, Cloud Edge, DC Edge Perimeter Firewall, Macro & Micro
  Segmentation). Teams fill in a product/platform and an SE response per concern.
- **HMF-Proctor-Guide.docx** — proctor only. Reference answers for every use
  case and the 0–100 scoring bands. Four use cases = 400 points total.

These mirror the live activity at the site root (index.html / proctor.html).
